# Catalogs

## Funcional

Catálogos maestros de Competencias y Resultados de Aprendizaje (RA). CRUD admin; listados activos para selects de seguimiento.

## Técnico

RA pertenece a una competencia (`competencyId` + `code` únicos). Soft flags `active`.

## Decisiones

Catálogo vs texto libre: se eligió catálogo para reportes homogéneos (decisión 2A del plan).

## Riesgos

Catálogo incompleto bloquea registros de seguimiento. Seed incluye ejemplos.

## Mejoras

Importación masiva de competencias desde Excel institucional.
